실제 연속 PIE 기록 · 약 16.4초. 아래 확인 결과 절의 접힌 원본 표는 월드 시간이며 영상 시작은 월드 약 10.55초입니다. 피격은 영상 약 11.7초, 다음 GuardIn은 약 12.9초입니다.

확인 방법

실제 PIE

GuardOut 시작을 0초로 둔 하나의 연속 실행입니다. 아래 요청은 재현 코드에서 실행한 것으로, 수동 키 입력 기록이 아닙니다. 적의 공격 요청 시점과 실제 충돌·피격 시점은 구분합니다.

가드 해제 후 진행 중인 적 공격의 피격 반응을 확인합니다. Hit 종료 후 다음 가드를 요청하고, GuardHold와 두 번째 가드 종료 후 상태를 확인합니다.

현재 개별 PDF 14쪽의 기존 전후 시연은 피해 20인 사례이며, 이 페이지의 별도 PIE 검증은 HP가 5,000에서 4,700으로 감소한 사례입니다. 서로 다른 실행의 피해 수치와 이동 설정을 구분합니다.

GuardOut 시작 0.075830초 후 피격이 들어왔습니다. 정리 전 Runtime=1 / Handlings=1에서 중단 후 Runtime=0이 됐고, 남은 정리 요청이 수락됐습니다. 실제 Hit 몽타주와 HP 5,000→4,700을 확인했습니다.

확인한 종료 경계·복원 방식

Overlay 정리만 수행할 때는 가드 의도를 유지하고, 전체 상태 정리에서는 가드·패링 창과 실행 상태를 해제하는 경계도 검사했습니다. 기본 이동 속도 설정의 복원은 최초 속도를 무조건 되돌리는 방식이 아니라 갱신된 기본 이동 요청을 따릅니다.

한계·미확인

달리기 동작 재개를 확인한 검사는 아닙니다.

별도 Sprint 단발 설정 사례는 입력이 유지되지 않아 기본 요청이 Run 600으로 바뀌었습니다. 이를 Sprint 키를 유지한 상태의 800 복원 검증으로 확대하지 않습니다.

PIE에서 적 공격은 테스트가 공개 공격 요청 진입점으로 선택했습니다. 자율 BT의 공격 선택이나 수동 PIE와의 이펙트 동등성을 검증한 자료는 아닙니다. 영상 기록은 평균 약 54.73fps, 종료부 readback 누락 1프레임으로 기록됐으며, 제출용 60fps 촬영 품질과 구분합니다.
