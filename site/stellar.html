작업 범위·기여

본인 작업

원하는 전투·AI 동작을 요구사항으로 구체화하고, 플레이 결과를 검토하며 보완 방향과 추가 확인 범위를 판단했습니다.

Codex 작업

코드 분석·구현과 자동 검증, 영상·문서 구성을 수행했습니다. 세부 구현의 최초 작성 범위는 확인된 기록을 기준으로 구분합니다.

이번 최적화 검증: 사용자는 측정 범위·환경 운영 조건과 결과 표현 기준을 정하고, Codex는 실행 자동화·측정·집계·근거 정리를 수행했습니다.

대표 구현

전투 판정 → 실행 전환 → 역할 배정 → 상태 관찰 순서로 구현을 살펴봅니다.

공격·피격 처리

공격자의 충돌 전달과 피격자의 방어·피해 판정을 분리합니다. 충돌 문맥과 전달 조건을 확인해 피해 입력을 전달하고, 피격자는 수신 조건과 방어 상태를 평가합니다. HP에 피해를 반영한 뒤 판정 결과를 리액션·피드백·공격자 측 처리에 전달합니다. 피해 반영과 리액션 실행 허용은 별도의 단계입니다.

문제 해결·검증

인식 지연 개선

같은 편 AI는 감지 후에 제외되던 대상입니다. 플레이어를 적대로 분류하고 Sight에서 적대 감지만 활성화해, 같은 편 AI를 감지 후보에서 미리 걸렀습니다.

120마리 · 최초 유효 대상 인식 지연 20.816초 → 1.053초

전후 각 3회의 실행별 p95 중앙값입니다. 전체 프레임 시간 개선은 확인되지 않았습니다.

프로젝트 PDF · 7–9쪽 ↗ (새 탭)AI 인지 지연 영상 ↗검증 상세 ↗

다수 AI 처리 비용 개선

공격 참여를 2명으로 유지하고 경계 참여를 6명으로 제한했습니다. 행동 판단 갱신 간격은 별도로 비교했습니다.

160마리 · 참여 제한 적용 후 프레임 시간 p95 22.3505 → 16.8966ms (24.40% 감소)
참여 제한 고정 후 갱신 조절 · 행동 판단 호출 764 → 329.25회/초 (56.90% 감소)

호출수 감소율은 해당 행동 판단 서비스에 한정됩니다. 갱신 조절의 추가 프레임 시간 개선은 반복 측정에서 뚜렷하지 않았습니다.

프로젝트 PDF · 10–12쪽 ↗조건별 비교 영상 ↗측정·검증 자료 ↗

피격 후 타깃 유지

피격 반응이 끝나기 전에 공격자 정보가 만료되는 문제를 다뤘습니다.

피격 반응이 끝난 뒤 공격자 기록의 유지 시간 계산 시작

오래된·중복 종료와 공격자별 만료를 검사했습니다. 공격자 파괴 후 대기 기록 정리 보완안은 원본 미반영입니다.
